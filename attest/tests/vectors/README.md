Test vectors from the Ampoule conformance v1.1 `extra/` suite (generated by
its `gen_extra.py`). Public keys and keyless forgeries only; no secret key.

- `weak_keys/NAME.pub` + `NAME.env.json`: the 8 small-order points (orders
  1, 2, 4, 8) and 2 non-canonical encodings of small-order points, each with
  an envelope "signed" with R = small-order point, S = 0, which verifies
  under cofactorless (non-strict) Ed25519. Every one must be refused.
- `copied/`: saved MCP results where the guest printed a copied
  `attestation:` line (with and without the real footer), the
  `qa-throwaway.pub` key that signed them, and the payloads.
